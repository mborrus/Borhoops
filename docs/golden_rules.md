# Golden Rules

Principles that guide all development on this project.

1. **Human-readable code.** A mid-level engineer should be able to read any file and follow what it does. No clever abstractions, no deeply nested logic, no "you had to be there" patterns. If it's hard to explain, it's too complex.

2. **Keep it lean.** No verbose docstrings, no unnecessary comments, no bloat. Every line of code added should earn its place. Readability comes from clean structure, not from explaining bad code with paragraphs.
