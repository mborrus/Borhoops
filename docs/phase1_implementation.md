# Phase 1: Feature Integration

Completed 2026-04-07. Expanded feature pipeline from 30 → 40 columns.

## What Was Built

### Odds Features (4 columns, `ODDS_COLS`)

**Source:** ESPN public scoreboard/odds API, scraped per-season into `data/odds/ncaab_odds_{season}.csv` (2013+).

**Transform:** `src/transform/transform_odds.py` maps ESPN team IDs → Kaggle IDs, computes DayNum. Output: `data/derived/ncaab_odds.csv` (27,736 rows as of 2026-04-07, growing as more seasons are scraped).

**Features:**
- `spread` — closing point spread from low-team perspective. Negative = low team favored. Conversion from home-team spread: `spread_low = Spread if home == low else -Spread`.
- `spread_abs` — absolute spread (game closeness proxy).
- `implied_prob` — spread → win probability via `1 / (1 + 10^(spread/15))`. K=15 calibrated for NCAAB.
- `over_under` — total points line.

**Training vs tournament:**
- Training: exact per-game closing line looked up by `(Season, DayNum, low, high)`.
- Tournament: season-average spread differential between the two teams as proxy (`odds_matchup_features`).

**Coverage:** ~45% of 2025 season games have odds data. Earlier seasons have lower coverage. NaN for women's games (ESPN odds are men's only).

### Poll Features (3 columns, `POLL_COLS`)

**Source:** ESPN Core API, scraped per-season into `data/polls/polls_{season}.csv` (2003+, AP and Coaches polls).

**Transform:** `src/transform/transform_polls.py` maps ESPN IDs → Kaggle. Output: `data/derived/poll_rankings.csv` (22,006 entries).

**Features (AP poll only):**
- `poll_rank_diff` — AP rank difference. Unranked teams default to 30.
- `poll_momentum_diff` — rank improvement from prior week (positive = climbing). Computed as `(previous - current)` for each team, then differenced.
- `weeks_ranked_diff` — cumulative weeks in Top 25 this season.

**Week mapping:** `DayNum // 7` (clamped to min 1). Falls back to most recent prior week via `_get_poll_entry()`.

**Coverage:** 100% — unranked teams get default values (rank=30, momentum=0, weeks=0).

### Roster Features (2 columns, `ROSTER_COLS`)

**Source:** ESPN public roster API: `https://site.api.espn.com/apis/site/v2/sports/basketball/mens-college-basketball/teams/{id}/roster?season={year}`

**Extractor:** `src/extract/extract_roster.py` — pulls per-player class year and injury status. Rate-limited at 0.2s/request. Saves `data/roster/roster_{season}.csv`.

**Transform:** `src/transform/transform_roster.py` — aggregates per-team experience stats, maps to Kaggle IDs. Output: `data/derived/roster_experience.csv`.

**Features:**
- `avg_experience_diff` — mean class year (Fr=1, So=2, Jr=3, Sr=4).
- `senior_pct_diff` — fraction of roster that are seniors.

**Limitation:** ESPN's roster API only returns meaningful data for ~2024+. Historical seasons return 0-3 players per team. As of 2026-04-07, only 2025 (4,637 players) and 2026 (5,747 players) are populated. These features are effectively unusable for model training until a historical roster source is found.

**Case sensitivity bug (fixed):** ESPN returns class abbreviations as uppercase ("SO", "JR") but the original `CLASS_MAP` used title case ("So", "Jr"). Fixed by lowercasing before lookup.

### Seed Feature (1 column, `SEED_COLS`)

**Source:** `data/kaggle/MNCAATourneySeeds.csv` (already loaded by `load_seeds()`).

**Feature:**
- `seed_diff` — tournament seed difference (lower seed = better). Unseeded teams default to 17.

**Training:** NaN for all regular season games (seeds assigned at tournament selection). XGBoost/LightGBM handle NaN natively. For tournament-specific models, historical tournament games could provide actual seed values.
